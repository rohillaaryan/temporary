# DevFolio - Personal Portfolio

A responsive personal developer portfolio built from scratch using semantic HTML, CSS layout systems (Flexbox & Grid), a custom color and typography system, and media queries. Deployed live via GitHub Pages.

## 🚀 Features & Technologies

- **Semantic Structure:** Built cleanly using semantic regions like `<header>`, `<main>`, `<section id="about">`, `<section id="projects">`, and `<footer id="contact">`.
- **Design System:** Custom CSS variables (`--brand`, `--ink`, etc.) for consistent color palette and clean typography.
- **Modern Layouts:** Utilizes **Flexbox** for the navigation header and **CSS Grid** for the project cards section.
- **Fully Responsive:** Mobile-friendly design featuring a `@media` query breakpoint and flexible images (`max-width: 100%`).
